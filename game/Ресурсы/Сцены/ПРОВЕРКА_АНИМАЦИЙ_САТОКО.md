# Проверка анимаций Сатоко

1. Скачай ветку `satoko-animation-test` или переключись на неё.
2. Положи ZIP `Universal Animation Library[Standard].zip` на Рабочий стол или в Downloads.
3. Запусти PowerShell-скрипт `game/tools/install_ual1.ps1` из корня проекта:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\game\tools\install_ual1.ps1
   ```
   Если ZIP лежит в другом месте, укажи путь через `-ZipPath`.
4. В Godot открой `Ресурсы/Сцены/satoko_animation_check.tscn` и запусти сцену.
5. Смотри Output: скрипт проверит наличие модели, UAL1, скелетов и список анимаций.

Важно: эта сцена пока диагностическая. Она НЕ переносит движения на Сатоко и не меняет исходную модель. Для ретаргетинга нужно подтвердить соответствие путей костей и проверить результат в запущенном Godot.
